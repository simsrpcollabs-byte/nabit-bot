KIDDO JS QUICK START

Railway:
1. Replace the old GitHub repo contents with these files.
2. Set Railway Variables: DISCORD_TOKEN and OPENAI_API_KEY.
3. Railway runs: npm start
4. Optional: DEV_GUILD_ID for quick command syncing.
5. Deploy logs should say: KIDDO online as ...

Local:
1. npm install
2. copy .env.example to .env
3. fill in tokens
4. npm start
