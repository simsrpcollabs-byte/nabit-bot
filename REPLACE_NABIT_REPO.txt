KIDDO — COMPLETE REPO REPLACEMENT

This package is meant to REPLACE the existing Nabit GitHub repository.

1. In the Nabit GitHub repo, delete the old Nabit source/config files.
2. Upload EVERY file from this package to the ROOT of the repo.
   Do not put them inside another folder.
3. Commit the replacement.
4. In Railway, keep the existing GitHub service connected to that repo.
5. Replace old Nabit environment variables with KIDDO's variables:

   DISCORD_TOKEN=your KIDDO Discord bot token
   OPENAI_API_KEY=your OpenAI API key
   OPENAI_MODEL=gpt-5.6-luna
   DATABASE_PATH=./kiddo.sqlite
   DEV_GUILD_ID=your Discord server ID (optional, recommended while testing)

6. Railway will use railway.toml and start KIDDO with:
   python main.py

IMPORTANT DATABASE NOTE
Railway service files can be ephemeral across redeploys. For permanent KIDDO profiles,
attach a Railway Volume and set DATABASE_PATH to the mounted path, for example:

   DATABASE_PATH=/data/kiddo.sqlite

Do not upload a real .env file to GitHub. Only .env.example belongs in the repo.
