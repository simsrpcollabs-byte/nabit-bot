KIDDO — COMPLETE JAVASCRIPT REPLACEMENT FOR NABIT

1. Open the GitHub repository currently used by Railway for Nabit.
2. Delete the OLD Nabit source/config files.
3. Upload ALL files from this ZIP directly to the repository root.
4. Commit the changes.
5. In Railway > Variables, make sure you have:
   DISCORD_TOKEN=<KIDDO bot token>
   OPENAI_API_KEY=<your OpenAI API key>
   OPENAI_MODEL=gpt-5.6-luna
   DATABASE_PATH=./kiddo.sqlite
6. You may optionally add DEV_GUILD_ID=<your Discord server ID> for instant slash-command syncing while testing.
7. Railway should automatically redeploy.
8. The startup command is npm start. There should be NO Python command.
9. Check Deploy Logs for: KIDDO online as ...

IMPORTANT:
- If Discord still displays the old Nabit name/avatar, Railway is using Nabit's Discord token. Change DISCORD_TOKEN to the token for your KIDDO Discord application, or rename the old Discord application to KIDDO.
- KIDDO needs Manage Webhooks for autonomous child proxy messages.
- KIDDO needs Manage Channels to create the private kiddo-assets channel for avatar storage.
- For persistent data on Railway, mount a Volume at /data and change DATABASE_PATH=/data/kiddo.sqlite.
