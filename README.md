# Nabit v4 — Generated Checkout Image

This version changes the flow to:

`/nabit` → enter name → browse → add items → bag → Generate Checkout → Nabit PNG → Place Order

## Important
The checkout image is generated by the bot itself using SVG + Sharp.

That means:
- the name is dynamic
- restaurant is dynamic
- items/quantities are dynamic
- fees and total are dynamic
- text stays crisp and exact
- no AI image generation is needed at runtime
- no Chromium/Playwright install is needed, which keeps Railway lighter

## Files
Upload all files flat to the GitHub repo root:
- index.js
- data.js
- renderer.js
- package.json
- .env.example
- README.md

Keep your existing Railway variables:
- DISCORD_TOKEN
- CLIENT_ID
- GUILD_ID

## Current limitation
Cart/order data is still in memory and resets on redeploy/restart. Supabase should be added next for persistence.
